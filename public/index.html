Embedded Hardware Engineering

Powered by Arduino Nano & Precision Electret Transducers

Each SilentAlert node operates an onboard 16MHz ATmega328P or ARM Cortex-M4 microcontroller wired to a low-noise MAX4466 microphone with automatic gain control (AGC).

50ms Fast Window Sampling: Captures audio waveforms at 1000Hz to calculate real peak-to-peak amplitude (Vpp).

Local Visual Feedback: Tri-color LEDs on pins D9, D10, D13 indicate status right at the physical sensor node.

115200 Baud Serial Bridge: Emits clean JSON packets consumed by the Node.js serial relay bridge.

arduino_nano_silentalert.ino UART 115200 bps 
#define MIC_PIN A0
#define SAMPLE_WINDOW 50

void loop() {
  unsigned long start = millis();
  unsigned int signalMax = 0, signalMin = 1024;
  
  // Collect 50ms peak-to-peak amplitude
  while (millis() - start < SAMPLE_WINDOW) {
    int val = analogRead(MIC_PIN);
    if (val > signalMax) signalMax = val;
    if (val < signalMin) signalMin = val;
  }
  double volts = ((signalMax - signalMin) * 5.0) / 1024.0;
  float dBA = 38.0 + (log10(volts + 0.05) * 42.0);

  // Transmit JSON telemetry to SilentAlert
  Serial.print(F("{\"node\":\"ARDUINO-NANO-01\",\"Library\":"));
  Serial.print(dBA, 1);
  Serial.println(F("}"));
}

Frequently Asked Questions

Detailed answers regarding sensors, thresholds, and installation.

How does the Arduino Nano sample and calculate real decibel SPL?

The MAX4466 sensor amplifies microphonic AC voltage output. The Arduino Nano reads analog pin A0 over a 50ms window, finds the peak-to-peak difference (Vpp), and applies a logarithmic transfer function dBA = 38.0 + (log10(volts) * 42.0) calibrated against a reference sound level meter.

Can I customize the decibel threshold for individual rooms?

Yes. Each monitored zone maintains an independent threshold limit in the MongoDB database (e.g., 50 dB for ICU recovery, 55 dB for study halls, 65 dB for robotics labs). If noise exceeds that room's specific limit, it flags an incident.

Does SilentAlert record human conversations or audio speech?

Absolutely not. SilentAlert enforces strict privacy by design. The Arduino microcontroller only computes mathematical Sound Pressure Level (SPL) numbers and discards raw audio instantaneously. No voice recording or eavesdropping is physically possible.

How do I connect my physical Arduino Nano via USB?

Flash the sketch in hardware/arduino_nano_silentalert.ino using Arduino IDE, then run node hardware/serial_telemetry_bridge.js COM3 on your terminal. The bridge instantly relays sensor packets to the web dashboard.
